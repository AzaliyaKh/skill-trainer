# Техническое задание: File Upload REST API

## 1. Назначение

Сервис загружает, выдаёт и удаляет файлы PNG и JPEG размером не более 5 МБ.

## 2. API

### `POST /files`

Принимает один файл. Для допустимого типа и размера создаёт уникальный идентификатор и возвращает его в JSON. Отсутствующий файл, размер свыше 5 МБ, `image/png`/`image/jpeg` несоответствие либо некорректный запрос дают HTTP 400 с JSON-ошибкой.

### `GET /files/{id}`

Для существующего `id` возвращает байты исходного файла с соответствующим типом содержимого. Неизвестный `id` даёт HTTP 404 с JSON-ошибкой.

### `DELETE /files/{id}`

Удаляет существующий файл и возвращает JSON. Неизвестный `id` даёт HTTP 404.

## 3. Хранение

Метаданные файла хранятся в памяти. Требования не определяют место хранения содержимого и сохранение после перезапуска.

## 4. Допущения и открытые вопросы

- Формат загрузки, схема метаданных, успешные HTTP-статусы и формат `id` не заданы.
- Нужно уточнить место хранения байтов, проверяется ли фактический формат файла и как трактуется граница ровно 5 МБ.

## 5. Критерии приёмки

1. Допустимый PNG или JPEG не более 5 МБ получает уникальный `id`.
2. `GET` по этому `id` возвращает исходные байты и тип содержимого.
3. После `DELETE` тот же `id` возвращает HTTP 404.
4. Файл свыше лимита, запрещённый тип и отсутствующий файл возвращают HTTP 400.
5. Неизвестный `id` возвращает HTTP 404; нескaчиваемые ответы представлены в JSON.
