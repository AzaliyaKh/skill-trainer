# Требования к генерации ТЗ: сервис загрузки файлов

## Цель

Подготовить краткое техническое задание на REST API: сервис загрузки файлов. Результат — один файл `answer.md` в Markdown на русском языке; реализация сервиса не требуется.

## Структура и стиль документа

Обязательные разделы: «Назначение», «API», «Хранение», «Допущения и открытые вопросы», «Критерии приёмки». В разделе API описать входы, успешный результат и ошибки каждой операции. Использовать нейтральные технические формулировки, точные имена маршрутов, полей и значения статусов. Сохранить идентификаторы API на языке интерфейса.

## Функциональные требования и ограничения

- `POST /files`: загрузить один файл и вернуть уникальный идентификатор в JSON.
- Допустимые MIME-типы: `image/png`, `image/jpeg`; максимальный размер — 5 МБ. Отсутствующий файл, превышение размера, запрещённый тип или некорректный запрос — HTTP 400 с JSON-ошибкой.
- `GET /files/{id}`: вернуть байты сохранённого файла с соответствующим типом содержимого.
- `DELETE /files/{id}`: удалить существующий файл и вернуть JSON. Неизвестный id при скачивании/удалении — HTTP 404 с JSON-ошибкой.
- Все ответы, кроме содержимого скачиваемого файла, — JSON. Метаданные допускается хранить в памяти; место хранения байтов и сохранение после перезапуска не определены.

## Неопределённые сведения

Не заданы: формат загрузки, формат id и метаданных, успешные HTTP-статусы, хранилище байтов, проверка фактического формата, единица МБ и трактовка границы ровно 5 МБ. Обозначить их как `[уточнить]` или открытые вопросы; возможные решения допускаются только с явной пометкой «допущение». Не добавлять обязательные авторизацию, внешнюю БД, нагрузочные показатели или иные неуказанные функции. Конкретные нормативные документы не заданы.

## Требования к итоговому результату

ТЗ должно покрывать все перечисленные операции, валидацию, форматы и хранение. Сформулировать проверяемые критерии приёмки для успешных операций, ошибок HTTP 400/404 и ограничений данных; не копировать готовую реализацию и не скрывать неизвестные значения.
