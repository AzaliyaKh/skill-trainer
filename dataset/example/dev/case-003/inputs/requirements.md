# Требования к генерации ТЗ: сервис сокращения URL

## Цель

Подготовить краткое техническое задание на REST API: сервис сокращения URL. Результат — один файл `answer.md` в Markdown на русском языке; реализация сервиса не требуется.

## Структура и стиль документа

Обязательные разделы: «Назначение», «API», «Хранение», «Допущения и открытые вопросы», «Критерии приёмки». В разделе API описать входы, успешный результат и ошибки каждой операции. Использовать нейтральные технические формулировки, точные имена маршрутов, полей и значения статусов. Сохранить идентификаторы API на языке интерфейса.

## Функциональные требования и ограничения

- `POST /shorten`: принять JSON с URL со схемой только `http` или `https`, создать уникальный активный короткий код ровно из 8 символов и вернуть его в JSON.
- `GET /{code}`: перенаправить по существующему коду на сохранённый URL.
- `DELETE /{code}`: удалить существующее соответствие; ответ — JSON. Последующее обращение к удалённому коду даёт HTTP 404.
- Некорректный JSON, отсутствующий URL, запрещённая схема или неверная длина кода — HTTP 400; неизвестный корректный код — HTTP 404. Ошибки представлять в JSON; все ответы, кроме перенаправления, — JSON.
- Допускается хранение соответствий в памяти процесса; сохранение после перезапуска не требуется.

## Неопределённые сведения

Не заданы: имена JSON-полей, схемы ответов и успешные HTTP-статусы, статус перенаправления, алфавит/генерация кода, обработка коллизий и повторное сокращение одного URL. Обозначить их как `[уточнить]` или открытые вопросы; возможные решения допускаются только с явной пометкой «допущение». Не добавлять обязательные авторизацию, внешнюю БД, нагрузочные показатели или иные неуказанные функции. Конкретные нормативные документы не заданы.

## Требования к итоговому результату

ТЗ должно покрывать все перечисленные операции, валидацию, форматы и хранение. Сформулировать проверяемые критерии приёмки для успешных операций, ошибок HTTP 400/404 и ограничений данных; не копировать готовую реализацию и не скрывать неизвестные значения.
