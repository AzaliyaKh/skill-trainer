# Противоречия
REQ-1 и REQ-2 противоречат друг другу: обязательное подтверждение по почте
делает регистрацию без почты невозможной. Нужно согласовать альтернативный
способ подтверждения или обязательность почты.

# Недостающие требования
REQ-3 не определяет измеримое время ответа, нагрузку и долю запросов.

# Рекомендации
Уточнить обязательность почты и измеримый критерий времени ответа при согласованной
нагрузке. Конкретные числовые значения должен подтвердить заказчик.
